# Zero-cost report
Costs: $0 for build (GitHub Actions free tier for public repos; private repos have a monthly minutes quota), $0 for signing (self-generated keystore), $0 for runtime (no servers). Distribution via GitHub Releases or sideloading; Google Play needs a one-time fee and is therefore not part of the $0 path. F-Droid/IzzyOnDroid are free options, not yet pursued.
